# 《潜伏之京城》设定集与分章大纲

> 一部以日据末期朝鲜（1939–1949）为背景的分支式文字冒险剧本。
> 借鉴《潜伏之赤途》的类型骨架：第二人称"你"、表面汉奸（亲日派）实为地下党、大量即死选项、问答循环、推理关、跨章节的延迟后果、"自己人比敌人更危险"的主题、以及战后清算中"无法自证"的结局。
> 主要人物、谜题与结局为原创；**历史事件、机构与组织一律使用真实名称**（创氏改名、朝鲜语学会事件、府民馆爆炸、反民特委、6.6 事件、国民保导联盟等），虚构人物嵌入真实事件的缝隙中。真实历史人物在史实范围内出现。

---

## 一、核心设定

**一句话**：1939 年，留学东京两年的青年姜仁宇回到京城（今首尔），在所有人面前变成一个"亲日派"。只有两个人知道，他是地下组织埋得最深的一颗钉子——代号「白鹭」。白鹭立在泥里，羽毛却不能沾泥；可十年之后，没有人再相信它曾经是白的。

**主题**
1. **名字**：创氏改名夺走朝鲜人的姓；地下工作夺走他的真名；解放后，"亲日派"三个字成了他唯一被承认的名字。
2. **语言与记录**：朝鲜语辞典原稿、被翻译篡改的供词、被烧掉的档案、日本女孩记下的民谣——谁有权记录历史。
3. **自己人**：杀死你的，多半是你要保护的人。
4. **无法自证**：解放后，证明自己是"共产党地下工作者"，在大韩民国等于自寻死路；不证明，就只能是亲日派。

**基调**：冷峻、克制，带黑色幽默。死亡结局短促，一句话点出"错在哪里"。Happy End 往往带反讽。

## 三、人物表

### 主角
**姜仁宇（강인우）** 23 岁（1939），男。早稻田大学政经科肄业。代号「白鹭」。创氏名「江原仁」（えはら じん）。
- 1937 年在徐明焕的引导下秘密加入地下组织「京城委员会」，读书会暴露后被捕。徐先生打点救出，并出钱送他去东京："用两年时间把'红'洗掉，变成一张白纸。"
- 表面：每日新报记者 → 宫本谦造的秘书兼翻译 → 1944 年起是"半岛青年代表"、演说家。
- 性格：聪明、克制，嘴上刻薄，心里软。越到后来越麻木，抽烟越来越凶。
- 随身物：一只黄铜烟盒（文先生给的，内有一支"特别的烟"）；第二章后可能还有韩素月给的银妆刀（은장도）。

## 五、剧本格式规范（所有章节必须遵守）

```
## 第N话 标题（时间·地点）

🖼 背景：钟路_夜.jpg
🖼 立绘：徐明焕_怒.png
♪ BGM：曲名
♪ 音效：拍桌子
≫ 黑屏渐入 / ≫ 黑屏渐出 / ≫ 连响四枪 / ≫ 一声枪响
★数值：[001:宫本信任] += 2
【旁白】第二人称叙述，主角称"你"。
【宫本谦造】角色台词。
【你】主角说出口的台词。
（你心想：……）——主角内心
▶ 选择：A ／ B ／ C
  ◆[A]
    ……该选项的内容（缩进两格）
    ⇒ 跳转：第N话 标题
  ◆[B]
    ……
    ★【剧终】结局名：一句话
    💡 提示：（可选，仅给部分死亡结局）
┐如果：[009:黑岩怀疑] ≥ 6
  ……
├否则：
  ……
└
┐循环（问答）
  ▶ 提问：……
  ◆[……] ★数值：[002:问题1] = 1 ……
  ◆[我没有问题了。] 判定 [008] ≥ N 才能跳出
└循环结束
```

写作要求：
1. 旁白用第二人称"你"。说话人一律标名字（原作不标，这里标出以便阅读）。
2. 每个死亡结局都要有一个简短、冷峻、带意象的收尾，并让读者明白"为什么这个选择是错的"。结局格式：`★【剧终】结局名`。
3. 正确选项不要总放在第一位，常常是第三、第四个"看起来最不像答案"的选项。
4. 问答循环要让角色借回答塑造自己（家世、信念、残忍）。
5. 遵守本设定集的人物性格、变量编号、关键道具；章节之间的衔接以本大纲为准。
6. 真实事件、机构用真名，细节尽量贴近史实；虚构人物可以参与其中，但不改变事件的基本事实（谁做的、何时、结果如何）。真实历史人物可以写进剧情（如韩龙云、李光洙、朴春琴、吕运亨、朴宪永、金九、卢德述），但只出现在史实记载的时间、地点和行为里；虚构的阴谋和私下交易只由虚构人物承担。
7. 文风参考：冷静的叙述，偶尔一句黑色幽默；人物说话要有各自的腔调（宫本文雅、黑岩轻佻、朴炳吉阴湿、具泰山市井、素月带刺、恩淑倔强、玄俊植像在开会）。

## 六、分章大纲

### 序幕·玄海滩（第1话）＋序章·北村（第2–8话）　1939.3

- **第1话 玄海滩**：关釜连络船上，第一人称独白——"我叫姜仁宇，23 岁。我回来，是为了当亲日派。"然后揭底：徐先生的安排，"红脸白脸"。⇒ 第2话。
- **第2话 序章**：京城站 → 北村徐家。徐先生正在给读书会的学生讲课（恩淑、金正浩、卢昌珉、黄有善、崔大植在场）。仁宇当众说出"朝鲜语没有前途，应该用国语（日语）思考"。徐先生大怒，把一本书砸在他脸上："滚！去找个地方好好读读你该读的书！"
  - 选择：把书扔回去 ／ 捡起书离开 ／ 跪下认错
    - 扔回去 → 第3话（出局：被学生们痛打，徐先生无法再联络你，1950 年……结局"无人认领"）

2. **卢昌珉回来**：若 014=1，卢昌珉以光复军国内挺进队成员身份潜回京城，在青丘书房旧址找到你："我在满洲想明白了，正浩……是正浩。"他交给你一份签了名的证词（证据④）。若 014=0 → 你在旧书堆里找到卢昌珉的诗集，扉页写着"给恩淑，待到春天"。
3. **金正浩**：
   - 若 015=1 → 第51话延迟死亡：金正浩微笑着请你去喝酒，朴炳吉在店外等着。"我一直知道你是谁，仁宇。我只是在等一个好价钱。"
   - 否则：可以揭穿金正浩（需要卢昌珉的证词或推理）。选择：杀了他 ／ 留着他（"他不值得一颗子弹"）——留着他会在终章出庭作证。杀他 → 第52话死亡（朴炳吉早就在保护他：金正浩是朴炳吉的线人）。正确是留着。
4. **炸弹**：素月小组（还有恩淑）计划在大会上引爆炸弹。素月找到你："你是第四个发言人，第三个发言的时候，离开讲台。"朴炳吉也找到你："我听说今天会有炸弹。你要是知道什么，现在告诉我，我们都能活。"
   - 告诉朴炳吉 → 第53话死亡（素月和恩淑被捕；朴炳吉笑着把你的名字也写进了报告："协助者"）
   - 什么都不说，按素月说的离开 → 爆炸。你被冲击波掀翻。
   - 留在台上（想保护台下的千鹤）→ 需素月好感 ≥7：素月冲上台把你拽下来，她自己受了伤（022=1）；否则 → 第54话死亡
5. **爆炸之后**：朴炳吉搜捕。素月受伤躲在明月楼。选择：去明月楼看她 ／ 去宫本家（千鹤在等你回信）
   - 明月楼 → 朴炳吉跟踪你 → 必须用银妆刀……（无刀 → 第55话死亡）。素月存活（022=1），她给你一份写给临政的证言："姜仁宇，代号白鹭，自 1940 年起多次协助本小组"（证据⑤）。
   - 宫本家 → 素月被捕后死于狱中（022=0）。
6. **8 月 15 日**：正午的广播。天皇的声音沙哑、听不懂的古日语。宫本在书房里坐了一整天。千鹤问："江原先生……现在我该怎么叫你？"⇒ 第六章

### 第六章·解放（第60–69话）　1945.8.15–1946.5

1. **8 月 16 日**：西大门刑务所打开，街上全是太极旗。人们开始寻找亲日派。仁宇的名字在每一张"亲日派名单"里排前十。
2. **宫本焚档**：宫本在南山庄烧档案。他问仁宇："你的那一份，要我留下，还是烧掉？"
   - 留下（宫本笑着签上自己的名字："江原仁，南山庄特别协力者。我会作证你是我最好的学生。"——这是"亲日"的铁证，012 不变，但终章多出一条死路）
   - 烧掉
   - 只留下其中一页（隐藏第三项）：那一页是宫本对你的评语"此人从未真正信服，可用而不可信"——这是另一种证据（证据加 1）
3. **送千鹤去釜山**：宫本请求你护送千鹤南下坐船。京城站挤满了要回国的日本人和寻仇的人群。站台上有人认出了千鹤（她是"南山庄宫本"的女儿）。
   - 交出千鹤 → 第61话死亡（人群转身认出了你。"江原仁"这个名字在站台上被喊了一百遍）
   - 带她跑 → 第62话死亡（两个人都没跑出广场）
   - 用朝鲜语对人群喊"她是教孩子唱阿里郎的老师"（需 016=0，千鹤会用朝鲜语唱出一段她搜集的民谣）→ 人群安静下来，有个老太太跟着哼了一句。你们上了火车。
   - 在釜山码头，千鹤把一本笔记本交给你："这是我记下的，关于你的事。如果有一天有人需要证明你是谁……"（证据⑥）——或者，选择**和她一起上船**（⇒ 尾声 HE·樱花）
4. **恩淑**：你回到京城，家门口站着一群学生，领头的是恩淑。他们来"清算亲日派江原仁"。
   - 沉默挨打 → 恩淑最后喊停："……够了。"恩淑信任 +1
   - 拿出徐先生遗书 → 若恩淑信任 ≥4 她相信了一半，抢过遗书收起来（012 -= 1，但恩淑信任 +3）；若不足 → 她当众撕碎，"伪造的，你们这种人什么都能伪造"（012 -= 1）
   - 逃跑 → 第63话死亡
5. **玄俊植**：他已是公开的左翼领袖之一，在美军政下活动。他对你说："组织不能认你。你太臭了。认了你，人民会怎么看我们？"他要你：继续潜伏到美军政做通译，报告 CIC 的动向。问答（天玑评价判定）：
   - 天玑评价 ＜4 → 他让你去执行一个"任务"，路上被"不明身份者"枪杀（第64话死亡）
   - ≥4 → 接受。
6. **朴炳吉**：他换上了美军政警察的制服。"我们又是同事了，仁宇。现在讲究的不是你过去干了什么，是你现在反不反共。"他想拉你一起"抓赤色分子"。选择：答应（⇒ 终章 A 线：你成了双重潜伏者）／ 拒绝（⇒ 终章 B 线）
7. **1946.5 精版社事件**：左翼被取缔，玄俊植北上，临走问你："跟我走吗？"
   - 跟他走 → 终章北行线（⇒ HE·人民的法庭 / 死亡）
   - 留下 → 终章

### 终章·反民特委（第70–79话）　1949.1–1949.6.6

1. 1949 年 1 月，反民族行为特别调查委员会开始逮捕亲日派。闵泳达社长被捕时还在念叨"时势"。仁宇在第二批名单上。
2. 牢房里的邻居是闵社长（喜剧/悲凉）。
3. **调查官徐恩淑**：她亲自审他。她说："我只问一次：我父亲，是你出卖的吗？"
   - 关键困境：**证明自己是"白鹭"——即共产党地下工作者——在国家保安法下等于自首。**不证明，就是亲日派。
   - 选择：
     - "是我。"（认下）→ 判决为亲日派，三年徒刑（⇒ 进入 6.6 事件）
     - "我是白鹭。"并拿出证据：012 ≥4 → 恩淑相信了，但她必须决定怎么写报告；012 ＜4 → 第71话死亡（"伪造证据、诬蔑烈士"罪加一等；后来在 1950 年 6 月的保导联盟处决中死去）
     - 沉默 → 恩淑："沉默也是一种回答。"
4. **公开审讯**：金正浩出庭（若第五章未被杀），指证"江原仁亲口对我说过他效忠天皇"，并暗示仁宇是"赤色分子"。
   - 当庭揭穿金正浩是 1937 年的告密者：需要卢昌珉证词（证据④）。成功 → 金正浩当庭崩溃。但——揭穿他等于承认自己是读书会成员、即共产党员。
5. **6 月 6 日**：朴炳吉带着警察冲进反民特委，"逮捕赤色分子调查官"。特委瘫痪。混乱中恩淑面对你，手里拿着你的案卷。
   - 结局由 012 证据、013 良知、011 恩淑信任 决定：
     - **HE·白鹭**（真结局）：012 ≥4、013 ≥6、011 ≥5。恩淑把案卷扔进火炉，说"姜仁宇已经死了，死在一个亲日派该死的地方"，给你一张去江原道山村小学的介绍信，上面是一个新名字。你离开时，朴炳吉在走廊上看着你，没有动。⇒ 尾声
     - **BE·无名**：证据不足或良知不足——朴炳吉认出你："赤色分子姜仁宇。"1950 年 7 月，保导联盟。
     - **BE·烈士**：你当众喊"我是白鹭"，被朴炳吉当场带走，以国家保安法处决。三十年后有人在档案里看到这个名字，以为是笔误。
   - **北行线**（第六章跟玄俊植走）：1948 年平壤，玄俊植已是内务部高官。他要你写材料指证南方的"间谍"——名单里有恩淑。
     - 写 → 1950 年 7 月首尔，你作为"人民审判员"坐在人民法庭上，被审的是恩淑。⇒ HE·人民的法庭（反讽结局：你活下来了，代价是一切）
     - 不写 → 死亡（"美帝间谍、日帝走狗"双重罪名）

### 尾声（第80–89话）

- **HE·白鹭**日后谈（第80话）：
  1. 1958 年东京：千鹤出版《半岛之歌》，书的最后一章写的是"一个叫 J 的朝鲜青年"："他用谎言保护了真话。"
  2. 1960 年 4 月：朴炳吉在学生示威后被曝光，他逃往美国，在洛杉矶开了一家洗衣店。他寄来一张明信片："我们都是穿着别人的皮活着的人。我的皮比较厚。"
  3. 1987 年：江原道山村，一位退休的小学老师（化名李白）在课堂上教孩子写"어머니"。辞典 1957 年出版完成。他的书架上有一套。
  4. 2005 年：恩淑 82 岁，向国家报勋处提交一份材料：徐明焕遗书、入党誓约书复印件、辞典寄存收据、卢昌珉证词、韩素月证言（按玩家实际取得的证据显示）。审查结果："资料不足，暂缓审议。"恩淑在报勋处门口抽了一支烟——她这辈子第一支烟。
  5. 最后一段：「天枢」的身份揭晓（文先生的哥哥？或者——徐明焕本人就是天枢；"白鹭"之所以从不登记在册，是因为他是天枢唯一亲手保护的人）。结尾句："白鹭立在泥里。它当然沾了泥。可它记得自己原来是什么颜色。"
- **HE·樱花**（第81话）：你和千鹤在下关上岸，你成了"江原仁"，在东京一所夜校教中文和朝鲜文。1958 年千鹤的书出版，你没有读。某天你在电视上看到汉城的学生示威，关掉了电视。"你用一个谎言换来了一辈子的安稳。只是每年三月，玄海滩的风总会吹进你的梦里。"
- **HE·人民的法庭**（第82话）：反讽结局，1950 年 7 月首尔的人民法庭；你签下了判决。"美丽的新国家正在向你招手。"之后一行小字："1953 年，南朝鲜劳动党系干部被清洗。"
- 各死亡结局可在此统一列出结局一览（可选）。
