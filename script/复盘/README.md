# 复盘与补课

每个死亡 / 出局结局有三层提示：

| 层 | 在哪里 | 写在哪 |
|---|---|---|
| 第一层 | 结局页，直接显示 | 剧本里结局后面的 `💡 提示：` 行（氛围化的一句话，保留不动） |
| 第二层 | 结局页，直接显示 | 本目录的 `复盘：` 行：讲清楚为什么死，以及大方向 |
| 第三层 | 结局页的「去青丘书房补课」按钮，玩家自愿进入 | 本目录的补课对话：徐明焕批改、文基哲讲解，明确指出死在哪一步、正确做法 |

本目录每章一个文件（`01-序章.md` … `08-终章.md`），由 `tools/build.py` 读入，按结局名匹配到对应结局。**不要改剧本正文。**

## 格式

```
## 结局名（与剧本里 ★【剧终】 后面的名字完全一致）
复盘：两三句。第一句说清楚这一死的因果逻辑；后面给方向。延迟死亡要点出源头在哪一章、哪一类选择，但不念出选项原文。
检查点：第N话｜选项原文
检查点名：第一章·小巷里的那张纸条
数值：009,010
评分：丁
【徐明焕】……
【文基哲】……
【徐明焕】……
```

字段说明：

- **复盘**（必填）：一段话，直接显示在结局页。不要谜语。
- **检查点**（可填多行）：玩家可以"回到那一刻"重新选择的位置。`第N话` 是那个选择所在的话号；`选项原文` 是那个选择里**任意一个选项**的原文（与剧本里 `◆[...]` 方括号内完全一致），用来定位那组选项。选最能纠正这次死亡的那个选择点：普通死亡就是导致死亡的那组选项；延迟死亡指向**埋坑的源头**。
- **检查点名**：按钮上显示的文字，格式「第X章·一句场景描述」，与检查点一一对应（多个检查点就写多行，顺序对应）。
- **数值**（可选）：与这次死亡有关的变量编号，补课页会显示玩家死时的数值，例如 `009` 显示为「黑岩怀疑：7」。
- **评分**：徐老师给这次死亡打的分，甲 / 乙 / 丙 / 丁（甲 = 死得情有可原、差一点就对了；丁 = 犯了低级错误）。
- **补课对话**：4–8 句。`【徐明焕】` 拿红笔批改，严厉、刻薄、短句，但看得出疼学生；`【文基哲】` 温和，倒大麦茶，负责把正确做法讲明白，可以直接说出选项原文。必须让玩家读完就知道：死在哪一章的哪一步、为什么、该怎么选。可以用 `【旁白】` 写一两句动作。

## 示例

```
## 好价钱
复盘：金正浩就是 1937 年和 1940 年两次告密的人，他把每一点"自己人"的痕迹都当成可以卖的货。你在他面前露过底，或者在第五章以"老同学"的身份当面揭穿他，等于亲手递给他一件好货，他转手就卖给了朴炳吉。对两头卖消息的人，要站在他害怕的那一边说话。
检查点：第17话｜冷笑一声
检查点名：第一章·小巷里那张纸条
检查点：第56话｜以宫本先生秘书的身份开口
检查点名：第五章·酒幕里的对质
数值：015
评分：丙
【徐明焕】（红笔在卷子上划了一道）丙。你被一个哭着的人骗了。
【徐明焕】我教过你：眼泪是最便宜的东西，便宜的东西，最容易拿去卖。
【文基哲】第一章，金正浩在小巷里摊开那张纸条，问"是你放的吧"。承认是死，沉默着把纸条烧掉也是死——烧掉，本身就是一个回答。
【文基哲】要"冷笑一声"，装作根本没见过那张纸。
【文基哲】到了第五章的酒幕，别用"老同学"的身份跟他说话。用宫本先生秘书的身份，用宫本那种日语，他就怕了。
【徐明焕】还有，揭穿了他，别杀。他还有用——留到特委的法庭上。
```
