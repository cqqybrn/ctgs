# 潜伏之京城 · 잠복의 경성

一部分支式文字冒险游戏。1939 年，留学东京的青年姜仁宇回到京城（今首尔），在所有人面前变成一个亲日派；只有两个人知道，他是地下组织埋得最深的一颗钉子，代号「白鹭」。故事从创氏改名一直走到 1949 年的反民特委与 6·6 事件，共 87 话、69 个结局。

类型骨架借鉴橙光游戏《潜伏之赤途》（第二人称叙述、大量即死选项、问答循环、推理关、跨章节的延迟后果、战后无法自证）。主要人物、谜题与结局为原创；历史事件与机构使用真实名称，真实人物只出现在史实记载的范围内。

## 怎么玩

- 直接用浏览器打开 `index.html`（双击即可），或开启 GitHub Pages 后访问仓库网址。
- 右上角工具栏：**后退**（退回上一步重选）、**存档**（8 个存档位 + 自动存档，可导出为文件）、**结局**（已达成的结局）、**音乐**（开关配乐与音效）。
- 存档和结局记录保存在当前浏览器里。
- 死亡后结局页直接显示提示与「复盘」；卡关时可以点「去青丘书房补课」：已故的徐老师批改、文先生讲解你到底死在哪一步，还可以「回到那一刻」，直接从埋坑的选择点重来。
- 标题页的「音源署名」可查看配乐和音效的作者、来源及许可，完整清单见 `assets/AUDIO_LICENSES.json`。

## 管理员模式 / 章节试玩

- 打开同目录的 **`admin.html`**。标题页点「选择章节」，或游戏右上角点「管理」。
- 先选章节，再选具体话，点击「进入所选话」。默认定位本章开头，也可直接看支线或结局。
- 状态可选「新局初始值」「顺境测试」「险境测试」「保留当前剧情变量」。预设只是进入该话前的测试数据；进入后仍按原剧情更新变量，不会自动补完前文，也不保证满足每条分支的条件。
- 「撤销上次跳转」恢复本次页面内上一次跳转前的剧情和历史；刷新页面后这个临时撤销快照不保留。
- 管理版与正式版的浏览器存档、检查点、结局和补课记录分开保存。点「退出管理，返回正式版」可回到正常游玩入口。
- 这是**公开的前端试玩调试入口**，不是带身份验证的后台；知道地址的人均可使用。正式版 `index.html` 不显示章节管理菜单。
- `admin.html` 与 `index.html` 都由构建脚本生成，不要手动修改。

## 在线试玩 / 发布

- 正式版：`https://cqqybrn.github.io/ctgs/`
- 管理版：`https://cqqybrn.github.io/ctgs/admin.html`
- 本地也可直接打开两份 HTML；或在仓库根目录运行 `python -m http.server 8000` 后访问 `http://localhost:8000/`。
- GitHub Pages 使用 `main` 分支根目录发布；`.nojekyll` 保留原始静态资源目录。推送后需等 Pages 构建完成。
- 离线分发时带上 `index.html`、`admin.html` 和完整 `assets/` 目录，保留 `assets/AUDIO_LICENSES.json`。不要只发送 HTML，图像和音频不内嵌其中。

## 目录

| 路径 | 内容 |
|---|---|
| `index.html` | 构建好的游戏（单文件，SugarCube 2.37.3） |
| `admin.html` | 构建好的章节试玩版，存档与正式版隔离 |
| `AGENTS.md` | 给 Codex 等代理的素材生成工作说明 |
| `script/chapters/*.md` | 剧本源文件，按章节分开，是唯一需要编辑的剧情来源 |
| `script/00-设定集与大纲.md` | 世界观、人物、变量表、格式规范、分章大纲 |
| `script/潜伏之京城-完整剧本.md` | 全部章节合并的阅读版 |
| `script/复盘/*.md` | 每个死亡结局的复盘、补课对话和检查点（格式见该目录的 README） |
| `assets/` | 素材插槽：`bg/` 背景、`char/` 立绘、`cg/` 事件图、`bgm/` 配乐、`sfx/` 音效 |
| `assets/README.md` | **素材规范与全部插槽清单**（给图片 / 音频生成用） |
| `assets/manifest.json` | 机器可读的插槽清单，每个插槽带文件路径、规格和生成提示词 |
| `tools/build.py` | 剧本 → 游戏的构建脚本 |
| `tools/asset_meta.py` | 画风规范、地点说明、人物外貌、配乐描述 |
| `tools/story.js` `story.css` `ui.tw` | 游戏运行时脚本、样式、标题页与界面 |
| `tools/explore_hua.js` `solve.js` | 自动试玩检查脚本 |
| `docs/原作精读笔记.md` | 对《潜伏之赤途》全剧的分段精读笔记（参考资料） |

## 改剧本 / 加素材之后

```bash
python3 tools/build.py
```

它会重新生成 `index.html`，并刷新 `assets/manifest.json` 与 `assets/README.md`（清单里的 `present` 字段会标出哪些插槽已有文件）。

素材只要按清单里的路径放进 `assets/` 就会生效，不需要改代码；缺失的插槽会被游戏安全跳过（不显示图片、不播放声音）。

## 剧本格式速查

```
## 第N话 标题
🖼 背景：钟路_夜.jpg          → 插槽 assets/bg/钟路_夜.jpg
🖼 立绘：徐明焕_怒.png        → 插槽 assets/char/徐明焕_怒.png（之后该人物说话时显示这个表情的头像）
♪ BGM：推理                   → 插槽 assets/bgm/推理.mp3（别名见 tools/asset_meta.py）
♪ 音效：拍桌子                → 插槽 assets/sfx/拍桌子.mp3
≫ 黑屏渐入                    → 分页（出现"继续"）
【旁白】……  【人名】……  【你】……
▶ 选择：A ／ B ／ C（需 [016:千鹤真相] = 0）
  ◆[A]
    ……
    ⇒ 跳转：第N话
★数值：[011:恩淑信任] += 1
┐如果：[012:证据] ≥ 4 且 [013:良知] ≥ 6 … ├否则： … └
┐循环 … （跳出循环） … └循环结束
★【剧终】结局名
💡 提示：……
⚑ 锚点：名字                     → 标记一个返回点
⇒ 跳转：⚑名字（按钮文字）        → 跳回该锚点（锚点须写在跳转之前，同一话内）
```

剧本里的「江原」（创氏名）在第一章以外按玩家的选择显示：选了「宫本仁」就显示为「宫本」，地名「江原道」不受影响。

## 自动检查

```bash
npm i -D playwright   # 或使用全局安装的 playwright
node tools/explore_hua.js   # 逐话把每个选项走一遍，报告报错、死路、未到达的结局
node tools/solve.js         # 搜索一条打出真结局 HE·白鹭 的完整路线
node tools/test_admin.js    # 管理入口、章节跳转、撤销、存档隔离和手机布局回归
```
