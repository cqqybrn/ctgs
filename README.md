# 潜伏之京城 · 잠복의 경성

一部分支式文字冒险游戏。1939 年，留学东京的青年姜仁宇回到京城（今首尔），在所有人面前变成一个亲日派；只有两个人知道，他是地下组织埋得最深的一颗钉子，代号「白鹭」。故事从创氏改名一直走到 1949 年的反民特委与 6·6 事件，共 86 话、68 个结局。

类型骨架借鉴橙光游戏《潜伏之赤途》（第二人称叙述、大量即死选项、问答循环、推理关、跨章节的延迟后果、战后无法自证）。主要人物、谜题与结局为原创；历史事件与机构使用真实名称，真实人物只出现在史实记载的范围内。

## 怎么玩

- 直接用浏览器打开 `index.html`（双击即可），或开启 GitHub Pages 后访问仓库网址。
- 右上角工具栏：**后退**（退回上一步重选）、**存档**（8 个存档位 + 自动存档，可导出为文件）、**结局**（已达成的结局）、**音乐**（开关配乐与音效）。
- 存档和结局记录保存在当前浏览器里。

## 改剧本 / 加素材之后

```bash
python3 tools/build.py
```

它会重新生成 `index.html`，并刷新 `assets/manifest.json` 与 `assets/README.md`（清单里的 `present` 字段会标出哪些插槽已有文件）。

素材只要按清单里的路径放进 `assets/` 就会生效，不需要改代码；缺失的插槽会被游戏安全跳过（不显示图片、不播放声音）。

## 自动检查

```bash
npm i -D playwright   # 或使用全局安装的 playwright
node tools/explore_hua.js   # 逐话把每个选项走一遍，报告报错、死路、未到达的结局
node tools/solve.js         # 搜索一条打出真结局 HE·白鹭 的完整路线
```
