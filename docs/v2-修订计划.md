## 一、宫本怎么知道你有问题，为什么放过你

- **问题**：第45话写"宫本没有怀疑你"，第60话焚档时他却说"我一直知道，从第一天就知道"，没有任何具体契机；"有些我放过了"也没有一个实例。
- **契机（第45话）**：素月小组扑空那晚，宫本愤怒地再拨 2-7-3-1。天玑答："您上个月不是已经要过一次了吗？我照念了。"宫本的声音停住，只说"……是吗。我打过。"挂上电话。看他拨过号的只有千鹤（那几天不在）和秘书。他隔着纸门看你一眼，什么也没说。第二天照常递墨："仁君，墨磨得太浓了。"
  - 第45话"宫本没有怀疑你"改成"黑岩没有怀疑你。宫本怀疑了，而且什么也没说。"
- **放过的实例**：黑岩之死。你拿宫本的号码把黑岩引去钟路后巷，宫本知道，没有拦。黑岩死后他拉《海行かば》问"这算不算一种幸福"，有了第二层意思。
- **不揭穿你的四层理由**：①自保：揭穿你，就要先向东京解释那个号码打给了谁，他和共产党天玑的交易会曝光；②借刀：黑岩在查他，一个会咬人的秘书正好对付黑岩；③退路：1944 年战局已定；④私心："余爱之，正以此"。
- 第60话"我一直知道"改成"从第一天我就猜到了。去年四月那通电话，只是让我不必再猜。"宫本仁分支"您为什么没有揭穿我？"补上自保一层。

## 三、宫本回不回京都（按是否当养子分线）

- **签了养子缘组届（宫本仁）→ 回京都**：
  - 他自己说："我原想死在这个半岛上。现在宫本家有儿子了，骨灰总得有人捧回京都——不如我自己走回去。"
  - 加上养子缘组要户主本人回本籍役场办理。
  - 九月把南山庄的钥匙交给美军："是一张很年轻的脸。"十月三人坐撤侨船。
  - 1949 年在京都去世，接现有第87话。第87话开头补交钥匙一段。
- **没签，或把名字还给他（江原仁／宫本仁还名）→ 留在京城**，见第四、五项。

## 四、新增：南山庄门口，父女告别（1945年8月23日凌晨）

插在第60话"托付"与"京城站"之间。签字回京都的路线不经过这里。

1. 宫本只送到门口：那段坡他下得去，上不来（回收第10话）。千鹤知道为什么，不劝。
2. 宫本拿出奚琴："四百一十二首里，你最喜欢哪一首？"千鹤用朝鲜语唱《阿里郎》，他伴奏。配乐用「奚琴·阿里郎」。
3. 宫本："这本书出不了了。日本不会再有人想读朝鲜的歌了。"千鹤不答；她的回答留到第65话釜山码头那句"……那我就写给朝鲜人看"。
4. 对你："她会说朝鲜语，可她不懂朝鲜。你懂。""路上不必对她说真话。……她会自己记下来的。""七月我说，和她一起走吧。……那句话，现在还算数。"
5. 千鹤深深鞠躬，下坡，没有回头。你回头：他一只手按着胸口，另一只手拿着奚琴的弓。最后一次见他。
6. 差分：读过评语页（032）多一句；宫本仁还名的玩家，他把空了的桐木盒子交给千鹤。

## 六、千鹤感情线（方案 A：补空白，克制）

千鹤在 1940.1–1942.11、1943.3–1945.7 两段完全没有戏。不写告白、不写亲吻，感情始终和"谎言"捆在一起。

- **第二章（1940–41）补一场短戏**：她请你译一首民谣的歌词，你故意译错一句，好护住唱歌的人；她照抄进笔记本。
- **第四章（1944）补一场**：和宫本的病合并。她从外地回来，发现父亲的药瓶换了位置，知道是你替父亲拿过药，郑重地拜托你："父亲的心脏，请你帮我看着。"她托付的，正是刚刚背叛她父亲的人。
- **第五章船票加几句**：她发现船票上的另一个名字是你，半开玩笑："父亲这是在替我说媒吗？"你的回答影响她在釜山会不会开口留你。
- **恩淑看见一次**（例如第四章公会堂演讲会后），作为她恨你的又一个理由，避免三角恋。
- **不新增好感变量**，用 [016:千鹤真相] 当主轴。HE·樱花分两版：说过真话 → 她嫁的是一个真人，结局句换成更温和的版本；一直在骗她 → 保留"你用一个谎言，换来了一辈子的安稳"。

## 七、待定：不打天玑电话的选择（第45话）

- 玄俊植明令"宫本那边的电话，你一样都不要碰"，现在却没有不打的选项。
- 设计（待作者确认）：在拨号前加「拿起听筒」／「不碰电话」。
  - 不碰：你不知道名单上是谁。结果同"什么都不做"（022 = 0，034 = 1，黑岩活），但良知 −1（不知情）而非 −2；天玑评价 +2（服从）。
  - 宫本拿不到契机：第六章他说的是"我猜了六年，你一次也没让我抓到"。宫本仁收养这一场相应差分："……这样的人，才配姓宫本。"
  - 第79话"1944年把名单交给宫本的是谁？"这一项在没打电话时隐藏；v2 分叉（需 034 = 0）自然不可达。
- 新变量：[050:打过电话]，0 = 没碰，1 = 打了。
