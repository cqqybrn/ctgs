## 一、宫本怎么知道你有问题，为什么放过你

- **问题**：第45话写"宫本没有怀疑你"，第60话焚档时他却说"我一直知道，从第一天就知道"，没有任何具体契机；"有些我放过了"也没有一个实例。
- **契机（第45话）**：素月小组扑空那晚，宫本愤怒地再拨 2-7-3-1。天玑答："您上个月不是已经要过一次了吗？我照念了。"宫本的声音停住，只说"……是吗。我打过。"挂上电话。看他拨过号的只有千鹤（那几天不在）和秘书。他隔着纸门看你一眼，什么也没说。第二天照常递墨："仁君，墨磨得太浓了。"
  - 第45话"宫本没有怀疑你"改成"黑岩没有怀疑你。宫本怀疑了，而且什么也没说。"
- **放过的实例**：黑岩之死。你拿宫本的号码把黑岩引去钟路后巷，宫本知道，没有拦。黑岩死后他拉《海行かば》问"这算不算一种幸福"，有了第二层意思。
- **不揭穿你的四层理由**：①自保：揭穿你，就要先向东京解释那个号码打给了谁，他和共产党天玑的交易会曝光；②借刀：黑岩在查他，一个会咬人的秘书正好对付黑岩；③退路：1944 年战局已定；④私心："余爱之，正以此"。
- 第60话"我一直知道"改成"从第一天我就猜到了。去年四月那通电话，只是让我不必再猜。"宫本仁分支"您为什么没有揭穿我？"补上自保一层。

## 七、不打天玑电话的选择（第45话）——已定

- 玄俊植明令"宫本那边的电话，你一样都不要碰"，现在却没有不打的选项。宫本出门前那句"有电话来，就说我不在"也是暗示。
- 拨号前加「拿起听筒」／「不碰电话」。新变量 [050:打过电话]：0 = 没碰，1 = 打了。
- **不碰**：你不知道名单上是谁，接"什么都不做"那一段（022 = 0，034 = 1，黑岩升官、朴炳吉接手京城的脏活，第五章已有差分，主体不动）。改几句措辞（你不知道被抓的会是谁）；良知 −1（不知情）而非 −2；天玑评价 +2（服从）。
- **碰了**：照原样走推理关；之后宫本从天玑的回答里拿到契机（第一项）。
- **宫本仁门槛（作者定）**：只有 050 = 0 的玩家，焚档那夜宫本才拿出养子缘组届。
  - **原则（作者定）**：宫本能接受"不信"，不能接受"出卖"。050 = 0 时他只知道你不信，不谈"怀疑你是叛徒"。
  - 050 = 0：收养一场照旧，台词改为："你从来没有信过我。这我早就知道。""可你也从来没有出卖过我。……至少，没有让我知道。""一个不信的人，肯替我守六年的规矩。这比一百个信的人都难得。""……这样的人，才配姓宫本。"
  - 050 = 0 时"您为什么没有揭穿我？"的回答围绕"不信不是罪"（例："揭穿你什么？揭穿你不信？这个半岛上不信的人有两千万，我揭穿得过来吗。"）。
  - 050 = 1：宫本取出桐木盒子，不拿养子缘组届："你已经选过一次了。四月那天夜里，你拿起了我的听筒。"他把那幅"宫本仁"烧掉，继续正篇（等同于"把名字还给先生"之后的流程）。
  - 第一项里宫本"我一直知道"的台词只用于 050 = 1；050 = 0 时他只是怀疑。
  - **人设一致性（作者定）**：宫本在【求情】【借名】【回拨】【来电登记】【全曲】【一个问题】【交换】里亲手处理掉你，【回拨】里你做的事和 050 = 1 完全一样。所以 050 = 1 时他知道却不杀你，必须靠**时机**解释，他是算计，不是心软：
    - 034 = 0（救了素月）：他知道时，黑岩刚说完"名单只经过南山庄"。秘书第二天出事，等于承认漏洞在他家，只能留着你，借你对付黑岩；之后新课长到任、战局已定，杀你只会多生是非。契机那场戏之后点明："他不是放过了你。他是暂时杀不了你。"
    - 034 = 1（打了电话但什么都没做）：他在下月例行通话才知道。名单没漏，你听见了却什么也没干。焚档时："你拿起了我的听筒。然后你什么也没做。……我到现在都没想明白，这是忠诚，还是胆怯。"
    - 两种情况都不给养子缘组届。
- 第79话"1944年把名单交给宫本的是谁？"这一项需 050 = 1。v2 分叉需 034 = 0，不碰电话的玩家自然进不去。

## 八、他为什么放过你：钟路署里的千鹤（作者提议，类比方别救冈山爱）

- 光靠时机只能解释他"暂时不动手"，还需要一笔欠账。
- **新增一场（第四章，1944年5–6月，所有路线都经过）**：千鹤下乡采风记下《새야 새야 파랑새야》（唱东学农民军全琫准的老歌，当局视为禁歌），笔记本上有歌词和唱歌人的名字。宪兵把她扣在钟路署（034 = 0 时是黑岩借她查宫本；其余是朴炳吉例行公事）。
  - ① 去钟路署把她带回来：说那首歌是讲"鸟"的童谣、是她译错了（回收第二章故意译错歌词）；内层选择：撕掉唱歌人名字那页／拿名字换她早点出来（良知 −2）。
  - ② 先告诉宫本先生：他自己下山领人，坡走到一半犯病；人情不是你的。
  - ③ 不管：三天后宫本托关系弄出她，笔记本被没收。
  - 新变量 [051:救千鹤]：① 成功 = 1。
- **效果**：
  - 050 = 0：加深千鹤线，宫本信任 +1；"父亲的心脏，请你帮我看着"接在这场之后。
  - 050 = 1 且 051 = 1：焚档时"你卖过我一次。你也把千鹤从钟路署带了回来。这笔账，我算了一年，算不平。所以我不杀你，也不把姓给你。我把千鹤交给你。"034 = 0 时可补一层：你替他除掉了离那个号码只差一步的黑岩。
  - 050 = 1 且 051 = 0：**延迟死亡【清账】**。第五章第50话开头，他不拿船票，只说"回去吧。路上小心。"（与【回拨】同句）。复盘检查点指向钟路署那组选项。
- 原则：宫本从不心软，只记账。所有他亲手处理你的结局都按这一条。结局数 +1。

## 九、黑岩之死是宫本借刀；"我不喜欢欠别人"

- **问题**：现在宫本对黑岩之死只有一段《海行かば》和"这算不算一种幸福"，玩家很难读出他知道是你、而且正合他意。
- **借刀（第45话，五月，034 = 0 路线，此时必然 050 = 1）**：黑岩开始查宫本后，宫本把你叫进书房："黑岩君在坡对面租了一间屋子。他很勤快。再勤快一点，就该找到那个号码了。""我年纪大了，号码总记不住。"他把 2-7-3-1 写在便笺上压在镇纸底下，出门。第二天素月的梅花笺到。内心独白点破："（你心想：那张纸条，是他留给你的。）（你以为你在替素月引黑岩。其实你也在替宫本。）"你在京城站对黑岩说的"宫本先生有一个号码"，成了宫本替你写好的台词。
- **事后**：第二天早上他照常递墨："墨磨得正好。"（与契机次日的"墨磨得太浓了"首尾相扣）然后接现有《海行かば》一段。
- **"我不喜欢欠别人"**：
  - 埋：第10话第一次进南山庄，你推辞他给的东西，他随口："收下吧。我这个人，不喜欢欠别人，也不喜欢别人欠我。"
  - 船票（第50话）：050 = 1 且 051 = 1："你把千鹤从钟路署带了回来。我还没谢过你。""我不喜欢欠别人。这张票，是还你的。""你留在这里，会被撕成碎片的。"050 = 0 保持父亲式好意的现状；050 = 1 且 051 = 0 → 【清账】。
  - 焚档摊牌（第60话）：050 = 1 时把账摆出来："四月那天夜里，你拿起了我的听筒。""黑岩君那件事，是我用了你。我们两清。""千鹤那件事，是我欠你的。船票我给过了。……现在，我不欠你什么，你也不欠我什么。""所以今天，我不杀你，也不给你我的姓。"随后托你送千鹤：账已平，这是他唯一一次不付账、只开口求人。
- **三张账单**：没碰电话 → 无账，只知道你不信 → 可收养；碰了电话、救了千鹤 → 用你一次、欠你一次、船票还清 → 放你走，不给姓，托付千鹤；碰了电话、没救千鹤 → 只剩出卖 → 【清账】。
