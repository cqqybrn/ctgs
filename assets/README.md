# 素材插槽说明（给美术 / 音频生成用）

游戏按固定路径加载素材：文件放到下表的路径就会自动出现，缺失的插槽会被安全跳过。
完整清单（含每个插槽的生成提示词）在 `assets/manifest.json`，本文件由 `python3 tools/build.py` 自动生成，请勿手改。

## 总体规范

- **场景背景**（`assets/bg/`，118/153 已就位）：16:9 场景图，JPG，1920×1080，质量 85 左右，单张不超过 600KB。 历史题材写实插画。故事主体发生在 1939–1949 年的朝鲜京城（今首尔），少数场景在日本、平壤或战后年代，以下面的场景描述为准。低饱和、偏冷的色调，轻微胶片颗粒，构图像 1940 年代的新闻照片或电影剧照。画面中不要出现可读文字、水印或现代物品；人物如需出现只作远景剪影，不画清晰面孔。
- **事件插图**（`assets/cg/`，0/1 已就位）：16:9 事件插图，JPG，1920×1080。 与背景同一画风的事件插图，可以有人物，但人物外貌须遵守角色设定。
- **人物立绘**（`assets/char/`，92/92 已就位）：半身立绘（腰部以上），透明背景 PNG，1024×1536，人物居中，头顶留约 8% 空白。游戏里会把它裁成圆形头像（取上方 40%），所以脸要在画面上部三分之一处。 与背景统一的写实插画风，统一左上方光源。同一人物的所有表情、服装必须保持脸型、五官、发型和年龄一致：先生成「常态」，再以它为参考生成其他表情。
- **配乐**（`assets/bgm/`，0/26 已就位）：MP3，128–192kbps，立体声。可无缝循环，长度 60–150 秒；首尾音量一致以便循环。 原创配乐，不要使用或模仿任何已有曲目的旋律。
- **音效**（`assets/sfx/`，0/49 已就位）：MP3，单声道即可，0.5–4 秒，开头不留空白，结尾自然衰减。 写实音效，1940 年代环境（没有现代电子声）。

## 生成流程建议

1. 先按「人物设定」为每个角色生成 `常态` 立绘，确定长相后，再以它为参考图生成其余表情和服装，保证同一人物前后一致。
2. 背景按地点分批生成，同一地点的不同时间（白天/夜/雪…）用同一构图，只改光线和天气。
3. 配乐需可无缝循环；音效开头不留空白。
4. 放好文件后运行 `python3 tools/build.py`，清单里的 `present` 会更新为 true，然后提交。
